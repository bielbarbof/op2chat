# OP2 Playtest Chat v0.2.0
Extensão comunitária não oficial para o Playtest Alpha de Ordem Paranormal RPG 2 no Owlbear Rodeo.

- Histórico persistente no Owlbear.
- Testes com atributo + perícia, RA/RB, DT e críticos.
- Tema automático por personagem atribuído.
- Integração com OP2 Playtest Fichas.

Instale usando a URL pública `/manifest.json` do seu Static Site.
