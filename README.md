# OP2 Playtest Chat — v0.7.8

Este é um conteúdo não oficial, publicado sob a Licença da Comunidade de Ordem Paranormal.

Extensão gratuita de Chat para Owlbear Rodeo integrada ao OP2 Playtest Fichas. Reúne mensagens, rolagens com pool de até quatro dados, DT compartilhada, cards sincronizados e histórico persistente.

O Chat abre como painel lateral persistente no lado esquerdo da Room. O painel é preparado em segundo plano para reduzir o tempo de abertura e permanece disponível enquanto você interage com o mapa. O X fecha o painel e o controle ao lado dele alterna entre o modo lateral e o modo maximizado.

## Instalação

Hospede esta pasta em HTTPS e cadastre a URL de `manifest.json` no Owlbear Rodeo. Para integração completa entre rolagens e personagens, instale também o OP2 Playtest Fichas.

## Uso

O Mestre pode definir a DT da mesa no cabeçalho. O rolador aceita d4, d6, d8, d10, d12 e d20, com até quatro dados por teste e no máximo três dados somados no resultado. Em rolagens com quatro dados, os três efetivamente utilizados são sinalizados no card.

Mensagens podem ser enviadas pelo botão ENVIAR ou por Enter. O botão segue a cor do Mestre ou do perfil do personagem atribuído.

## Compatibilidade e privacidade

- Desenvolvido para Owlbear Rodeo com SDK 3.1.0.
- O código não envia mensagens ou estado de personagem para um serviço próprio; a persistência utiliza o ambiente do Owlbear.
