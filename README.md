# OP2 Playtest Chat v0.6.2

Extensão comunitária não oficial para Owlbear Rodeo, integrada ao OP2 Playtest Fichas v0.6.2.

A v0.6.2 parte diretamente da **v0.6.1** e preserva a interface e as ferramentas administrativas já aprovadas.

## Alterações desta versão

- Hierarquia tipográfica consolidada com Girassol + família Arpona através das webfonts fornecidas pelo usuário.
- `prepare_fonts.py` instala Arpona Light, Regular, Medium e Bold e aceita ZIPs com pastas internas diferentes.
- D6 recebe nova correção óptica global (`scale(.82)`) sem alteração do PNG original.
- Ícone da extensão Chat passa a usar uma versão do D20 com margem transparente segura, evitando o corte inferior no Owlbear.
- Seletor de dados por ícones, botão de lixeira do Mestre e cards/notificações de rolagem da v0.6.1 foram preservados.

## Base

A linha 0.6.x é a base canônica do projeto.
