# Changelog — v0.4.0

- Painel TESTES convertido em drawer responsivo; não redimensiona nem esmaga o Chat.
- Hierarquia tipográfica revista fora dos componentes já aprovados.
- Card de rolagem mantém a linguagem aprovada, mas agora mostra o símbolo do dado junto do valor.
- Resultado reorganizado como RESULTADO + estado; RA, RB e DT removidos da apresentação.
- Indicador gráfico de sucesso/falha adicionado.
- Efeitos temporários aparecem nos testes com dados adicionais e são consumidos ao usar um teste compatível.
- Integração e persistência com Fichas mantidas.
- Conjunto de ícones de dados redesenhado para aproximar a geometria do playtest.
