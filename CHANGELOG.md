# OP2 Playtest Chat — v0.2.0

## Visual
- Interface redesenhada para a linguagem editorial dark do Playtest Alpha.
- Cabeçalho reduzido a **CHAT**.
- Tema muda automaticamente conforme o personagem atribuído: Executor vermelho, Analista azul, Vigilante verde.
- Tipografia preparada para Girassol, Arpona e Agharti via fontes locais, sem redistribuir os arquivos de fonte.
- D4, D6, D8, D10, D12 e D20 usam assets SVG dedicados.
- Ícone da extensão passa a usar o D20.

## Rolagens
- Cards de teste redesenhados e alinhados ao pop-up das fichas.
- Falha e falha crítica usam vermelho; sucesso crítico recebe estado próprio.
- RA, RB, DT, dados individuais e resultado ganharam hierarquia de leitura maior.
- Área de dados livres remove textos redundantes.

## Testes rápidos
- Jogadores só acessam a ficha que o mestre atribuiu a eles.
- Mestre continua podendo escolher qualquer personagem ou fazer teste manual.
